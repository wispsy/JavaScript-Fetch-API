# Changelog

## 0.2.0

- Move the Python import package from `javascript` to `fetch_api` to avoid a
  namespace conflict. Update imports to `from fetch_api import fetch`.
- Remove the placeholder `main()` function.

## 0.1.0

Initial release of `JavaScript-Fetch-API` for Python 3.14+.

- JavaScript-style Fetch API using the Python standard library.
- Promise chaining, request and response objects, headers, and JSON traversal.
